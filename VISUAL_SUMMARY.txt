┌────────────────────────────────────────────────────────────────────┐
│ 🔐 FLUJO DE AUTENTICACIÓN                                          │
└────────────────────────────────────────────────────────────────────┘

1. REGISTRO
   ├─ Usuario llena formulario en auth.html
   ├─ js/auth.js hace POST a /api/auth/signup
   ├─ Backend hashea contraseña con bcrypt
   ├─ Crea usuario en MySQL
   └─ Retorna mensaje de éxito

2. LOGIN
   ├─ Usuario ingresa email + contraseña
   ├─ js/auth.js hace POST a /api/auth/login
   ├─ Backend verifica contraseña
   ├─ Genera JWT token (válido 7 días)
   ├─ Retorna token
   ├─ Frontend guarda token en localStorage
   └─ Redirige a dashboard.html

3. ACCESO A DASHBOARD
   ├─ dashboard.html se carga
   ├─ js/dashboard.js verifica si hay token
   ├─ Si no hay token → redirige a auth.html
   ├─ Si hay token → carga usuario y dashboard
   ├─ Todos los requests incluyen header: Authorization: Bearer <token>
   └─ Backend verifica token en middleware/auth.js

4. LOGOUT
   ├─ Usuario hace clic en "Cerrar Sesión"
   ├─ Frontend borra token de localStorage
   └─ Redirige a index.html
